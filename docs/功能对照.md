# 用户需求、原生功能与 Kokomi 对照

核对日期：2026-10-28。目标：AstrBot 4.29.3+；Kokomi 参考仓库 main 树 `587e041bebcde158527886e77b02a2f0c37acf34`，其中 V5 尚在开发。本项目没有把它的 mock 响应作为真实战绩。

## 一、继承水表机器人

`/wows` 是可独立运行的公开数据实现；`/wws` 是原版引擎桥接。原版后端拥有的历史数据库、榜单和评分不会随适配器源码自动获得。安装原版引擎并具备其后端访问权限后，桥接传递原始命令、用户 ID、平台标识和会话标识，返回它生成的文字或图。

依据原项目 [V4 命令文档](https://github.com/SangonomiyaKoko/Kokomi_Bot/blob/main/docs/command.md)、[排行榜文档](https://github.com/SangonomiyaKoko/Kokomi_Bot/blob/main/docs/Leaderboard.md) 和 [V4 接入教程](https://github.com/SangonomiyaKoko/Kokomi_Bot/blob/main/README_OLD.md)，对应关系如下。

- **绑定和账号概览**：原生 `/wows 绑定`、`战绩`；原版 `/wws` 透传 bind/basic/info 等相关命令。
- **总体、单船、舰种、船池**：原生 `战绩`、`单船`、`舰种`、`船池`。数据为有公开历史战绩的舰船；当前是否仍在港口须由有权限的原服务提供。原版 ship/ships 与过滤逻辑透传。
- **随机、单野、分队、排位、公会战**：原生 `--mode` 指定口径，不把不同模式相加当同一指标；原版模式和赛季能力交给原服务。API 没返回某模式时明确报告缺数据。
- **近期和单船近期、逐局近期**：原生 `近期` 按累计快照差值计算；原版 recent/recents 可使用其已有历史库。桥接不生成假逐局数据。
- **单船排行榜、全球榜、个人全服名次、缓存更新**：原生排行限本会话候选池；原版 top/me/global/update 及全球/服务器参数原样透传，资格门槛、数据覆盖和刷新权限仍由原服务判断。
- **PR、其它评分与校正**：原版由其算法、期待值和数据库计算。原生缺期待值时不生成虚构 PR，也不会用普通场均替代个人评分。
- **公会概况、赛季、公会历史**：原版 clan/cw/season/history 查询通过桥接；原生 WG 客户端也提供公开公会接口，当前普通命令入口以战绩为主。
- **签名卡、行动模式、详细扩展统计**：原版 card/oper/info 由原引擎输出，原图经桥接发送至 AstrBot。
- **帮助、主题、语言、别名、管理员能力**：原版支持哪些命令由实际安装版本确定。桥接不重新解释其参数，不接受客户端传入的 `is_admin` 标记作为上游权限；管理员身份由原版配置维护。

V5 文档中存在的语言、主题、别名、评分模式等规划，不代表当前 main 已完成实现。V4 不支持的 V5 命令无法通过桥接凭空实现。应先让原版在自身环境中完成真实查询，再接 AstrBot，详见 [Kokomi 接入](Kokomi接入.md)。

## 二、浩舰所有舰船的详细资料

插件发现网站当前公布的数据版本，再从同一版本查询舰船目录与详情。目录可检索中文、英文、简拼、WG ID 和 index。比较数据包含十二类；原始详情包含模块、升级品、技能、信号旗、消耗品等站点所提供的字段，完整导出 JSON。

“所有”指 **该站点所选版本和当前访问权限实际返回的舰船与字段**；未公开、未实装或网站尚未更新的内容不能捏造。图中/表中原始字段不擅自换算为未知单位。登录由用户在官网完成，提供本人授权会话，插件检测明确站点登录标记。失效时提示重新登录，不绕过验证码或付费权限。

## 三、高级攻略与赛事、教学

知识库包含原创战术推演、有来源事实和教学摘要，分别打标；模型可按问题调用检索工具。赛事采用能够核对的官方规则、结果与赛制；具体逐局录播需授权文字记录、时间戳和人工复核后导入。本项目不宣称已观看并消化所有高级赛事录像。

高级攻略支持教练式问答；它不是模型训练或冠军能力认证。版本敏感参数按现场查询的数据回答；赛事选船和禁用规则按对应届次解释。

## 四、看战绩图、分析瓶颈与意识

结构化查询结果直接作为证据送给模型。第三方截图支持同条附件与引用消息中的图片；需要配置支持图片输入的模型。先核对统计标题、模式、场次、时间和单位，模糊数值不猜。

模型将聚合数据能支持的判断与录像才能验证的意识假设分开，优先给最多三项训练和验收指标。战绩本身没有首死时间、地图位置、决策过程，就不会据此断言“你一定冲太快”。

## 五、吐槽与战局分析

可以针对匹配体验、阵容、交叉火力、视野缺口、队伍推进节奏表达不满，同时把讨论落在具体可观察情境。不会把黑箱操控、针对特定账号等未经证实的说法当事实。输入地图、时间、点数、双方阵容、血量与位置，可做条件化战局复盘。

## 六、主动回复

监听 AstrBot 的平台消息事件，不需要用户逐条 @。明确游戏词触发；同一会话近期游戏上下文可承接“队友、匹配、胜率”等较弱关键词。不同会话隔离，机器人自己发言不触发，重复平台事件不重复回复。

疑问不受普通讨论插话间隔限制；同一会话仍有分析在进行时，不再叠加第二个请求。一般讨论有可配置的冷却，避免连续刷屏。管理员可按会话开关；配置列表为空时按用户要求默认覆盖所有接入会话。

平台消息权限决定可见范围。插件不会补读全部历史聊天、监听电脑所有应用、扫描服务器日志或读取未授权会话。截图没有任何文本说明且无明确指令时，不会盲目把每张图当游戏战绩分析。
