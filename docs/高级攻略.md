# 高级攻略阅读入口

完整正文保留在 [`knowledge/advanced_guide.md`](../knowledge/advanced_guide.md)，共72节，插件检索与人工阅读使用同一份原文，避免维护两份相互冲突的攻略。

建议按需求阅读：

- **大局意识与资源交换**：第01至17节，胜利路径、阵容能力、分路、有效火力、交叉火力、推进与撤退、积分和时间。
- **机制与舰种理解**：第18至46节，炮弹与装甲、鱼雷、隐蔽、消耗品，以及驱逐、轻重巡、战列、航母、潜艇、反潜和混合舰。
- **随机、排位、公会战与赛事**：第47至52节，区分赛制，训练选船、协同、指挥与观察专家教学的方法。
- **战绩瓶颈与截图复盘**：第53至62节，统计口径、近期差值、样本、PR、高伤低胜、存活率、命中率与首次不可逆失误。
- **吐槽、沟通和训练**：第63至72节，讨论匹配、评价队友行动、单目标练习、残局和持续更新知识。

赛事事实与教学摘要另见 [`sources_and_events.json`](../knowledge/sources_and_events.json)。事实、教学简介和原创建议有不同标签；没有把未观看的比赛录像写成逐局战术结论。涉及具体船只参数时，用 `/wows 浩舰` 查询当前可见版本。

机器人中可直接发：

```text
/wows 攻略 弱侧如何拖延并保留撤退路线
/wows 攻略 驱逐舰什么时候不应该进点
/wows 攻略 高伤害低胜率需要检查什么
/wows 攻略 KOTS XVI
/wows 分析 这局我方领先200分但少两艘船，应该继续追还是守点
```

最后一条的结论还取决于剩余时间、占点、位置、血量、视野与敌我阵容，机器人应据此给条件化建议。
